- Profile: [eiich](https://atcoder.jp/users/eiich)
- Progress: [AtCoder Problems](https://kenkoooo.com/atcoder/#/table/eiich)
  - Table: 各コンテストの問題をどれくらい解いているかを確認できる．
  - User > Achievement / Difficulty Pies: 解いた問題数や難易度ごとの分布などを確認できる．
  - User > Progress Chart: これまでの活動状況を時系列で確認できる．
  - User > Language: 解答に用いたプログラミング言語の分布を確認できる．
