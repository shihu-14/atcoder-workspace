# AtCoder Workspace

## kyopro_library

`kyopro_library` には、自作の競技プログラミング用ライブラリを置いています。
一部の実装は外部資料や他の実装を参考・引用しており、その場合は各ファイル内に参照元リンクを記載しています。

## src

`src` には、これまで参加・演習したコンテストの解答コードを置いています。
ABC、ARC、AHCなどのコンテスト種別ごとに解答を管理しています。
